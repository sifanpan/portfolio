# Relief medal style v1 (frozen snapshot)

Monochrome relief + eraser reveal used by the Claim Medal card. This folder is **read-only reference**; runtime still uses files under `src/`.

## Visual traits

- Background matches lit surface: `#f2f2ee`
- Key light top-right, shadow bottom-left; volume from height + normal blend
- Mouse wipe reveals `base.png`; stroke trail dissolves back to relief on release

## Contents

| File | Purpose |
|------|---------|
| `style.json` | All numeric parameters |
| `shaders/` | Frozen GLSL copies |
| `preview-relief.png` | Pure relief preview (no reveal) |
| `assets/` | Height / normal maps for v1 |

## Textures

- Color base: `../base.png`
- Height / normal: see `assets/`, generated by `scripts/generate-medal-normal.py` (blur 2.8, strength 3.2)

## Code entry points

- Constants: `src/lib/medalReveal/reliefStyle.v1.ts`
- Shader: `src/lib/medalReveal/shaders.ts` → `RELIEF_ERASE_FRAG`
- Component: `src/components/playground/MedalReliefCanvas.tsx`

## Restore / iterate

- **Restore v1**: sync `src/` from this folder’s `style.json` and `shaders/`
- **New version**: copy to `relief-style-v2/`, add `reliefStyle.v2.ts`; do not overwrite v1
