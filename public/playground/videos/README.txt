Playground — AI video assets

Place AI keyframe-generated videos here. Recommendations:
- Format: mp4 (H.264) preferred for web compatibility; mov also works
- Naming: lowercase + hyphens, e.g. keyframe-film-01.mp4
- Poster: optional same-name poster, e.g. keyframe-film-01-poster.png
- Size: keep each file < 20MB to avoid slow loads

After adding files, set paths on the matching entry in src/data/playground.ts, for example:

  cover: 'playground/videos/keyframe-film-01-poster.png',
  href: 'playground/videos/keyframe-film-01.mp4',

Card behavior: muted loop preview on hover; click to expand with controls.
